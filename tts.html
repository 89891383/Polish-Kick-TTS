FAQ

Na PC i OBS TTS startuje automatycznie — bez klikania. Na iPhone (IRL Pro, Moblin) iOS może wymagać jednego tapnięcia gdziekolwiek na ekranie przed pierwszym TTS (ograniczenie Apple, nie da się tego w 100% obejść w przeglądarce). Po starcie strony overlay nie blokuje już widoku.

Tak — w 100% darmowy. Nie wymaga konta, klucza API ani subskrypcji. Wystarczy wygenerować link i dodać go jako Browser Source w OBS.

Wklej pełny link (np. https://kick.com/adamcy) lub sam nick. Generator automatycznie wyciągnie tylko nazwę użytkownika i zbuduje gotowy URL TTS.

Tak. Dodaj wygenerowany link jako Browser Source. Ustaw dowolny rozmiar (np. 800×600) — strona jest przezroczysta i niewidoczna na streamie.

Broadcaster może natychmiast przerwać aktualnie odtwarzane TTS wpisując !skiptts na czacie. Kolejka FIFO kontynuuje od następnej wiadomości.

Zalecane są głosy Wavenet i Standard (Google Speech v2) — szybki prefetch i brak limitów zapytań na dużych streamach. Chirp3 HD korzysta z API v1: najwyższa jakość, ale na busy streamach może pojawić się limit (błąd 429).

Parametr speed (-3 do +3) dla Oddcast, Microsoft i Chirp3 HD (v1): ujemne = szybciej. Google v2 (Wavenet/Standard): +1 szybciej, -1 wolniej (zakres -1 do +1). StreamElements bez speed.

Dla Oddcast, Microsoft, StreamElements i Chirp3 HD (v1): pitch od -10 do +10. Dla Wavenet/Standard (v2): osobny pitch 0.01–0.99 (domyślnie 0.50). Oddcast/SE emulują ton przez Web Audio.

W generatorze zaznacz uprawnienia: Każdy, Obserwujący, Moderator, OG, Subskrybent, VIP. Broadcaster ma zawsze pełny dostęp niezależnie od ustawień.

Domyślnie tak — opcja Wymagaj !tts jest włączona. Możesz ją wyłączyć w generatorze, wtedy każda dozwolona wiadomość będzie czytana.

Linki domyślnie ignorowane (można włączyć czytanie jako LINK). Opcja „Bez emotek” domyślnie włączona — usuwa emoji i emotki Kick. Wyłącz ją, jeśli chcesz je czytać.

Komendy broadcastera

!skiptts — natychmiastowe pomijanie aktualnie czytanej wiadomości TTS

Jako broadcaster wpisz !skiptts na czacie Kick, aby zatrzymać długą lub nieodpowiednią wiadomość TTS bez czekania na koniec odtwarzania.

Jak używać — szczegółowy przewodnik

Konfiguracja generatora

W polu kanału wklej pełny adres swojego profilu Kick, np. https://kick.com/adamcy — system automatycznie rozpozna nick adamcy i wyświetli podgląd kick.com/adamcy. Możesz też wpisać sam nick lub adres z prefiksem @.

Wybierz głos z listy 13 polskich opcji. Dostosuj głośność (0–100), prędkość mowy (-3 szybciej do +3 wolniej) i ton (-10 niższy do +10 wyższy). Ustaw uprawnienia — domyślnie TTS mogą używać moderatorzy, OG i VIP.

Integracja z OBS

Skopiuj wygenerowany link z sekcji pod formularzem. W OBS Studio: Sources → Add → Browser. Wklej URL, ustaw Width 800 i Height 600. Zaznacz „Refresh browser when scene becomes active". Źródło jest niewidoczne na streamie — odtwarza tylko dźwięk TTS.

Widzowie piszą na czacie !tts Twoja wiadomość (gdy włączony pretext). Broadcaster może w każdej chwili przerwać odtwarzanie komendą !skiptts. Kolejka FIFO gwarantuje, że wiadomości są czytane po kolei bez nakładania się.

Wskazówka: Po zmianie ustawień w generatorze URL aktualizuje się automatycznie — nie musisz klikać żadnego przycisku. Wystarczy ponownie skopiować link i zaktualizować Browser Source w OBS, jeśli już go dodałeś.

Bezpieczeństwo i prywatność

Lokalne

Generator działa w przeglądarce — żadne dane nie są wysyłane na serwer. Konfiguracja jest w URL.

OBS

W trybie streamu strona jest przezroczysta i niewidoczna. Tylko WebSocket Kick i API TTS są używane.

Open

Projekt open source na GitHub Pages. Możesz hostować własną kopię lub używać oficjalnego linku.
